# bloom. — version mobile mockup

Prototype complet du simulateur d’épargne bloom. basé sur le visuel mobile validé.

## Lancer le projet
Ouvrir `index.html` dans un navigateur moderne ou publier le dossier sur GitHub Pages.

## Structure
- `index.html`
- `css/` : styles
- `js/` : calculs, graphique, interface, thème et traductions
- `assets/images/` : illustrations SVG

Cette version est autonome et ne nécessite aucune dépendance externe.
